# Materiały źródłowe

Tutaj trafiają pliki badawcze i notatki oraz czytelne transkrypcje utworzone z eksportów. Transkrypcje powinny wskazywać plik oryginalny, identyfikator rozmowy i dostępne daty. Badania zachowują autora, datę i adres źródła, jeśli są znane.

Stan: brak opracowanych źródeł.
